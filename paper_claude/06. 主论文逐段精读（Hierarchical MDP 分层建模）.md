## 段落1：引言与动机

### 【英文原文】

To address the curse of dimensionality in the original MDP, we propose a hierarchical MDP that decouples the decisions of budget allocation and node selection. As shown in Fig. 3, the hierarchical MDP consists of two levels: the high-level MDP and the low-level MDP. The high-level MDP determines how to allocate the sampling budget to each sensor, and the low-level MDP selects the sampling node for each sensor based on the allocated budget. The two levels are connected through the budget allocation, where the high-level's action becomes the low-level's constraint.

### 【简体中文翻译】

为解决原始MDP中的维数灾难问题，我们提出了一种分层MDP，将预算分配和节点选择的决策解耦。如图3所示，分层MDP包含两个层次：高层MDP和底层MDP。高层MDP决定如何向每个传感器分配采样预算，而底层MDP根据分配的预算为每个传感器选择采样节点。这两个层次通过预算分配相互连接，其中高层的动作成为底层的约束。

### 【三梯度深度解释】

#### 🐣 3岁小孩级别解释

想象你有一个非常非常复杂的玩具，这个玩具有很多很多按钮。如果让你一下子按对所有的按钮，你会觉得很困难，对不对？

聪明的叔叔阿姨想到了一个好办法：把这个大任务分成两个小任务。

第一个小任务是"分糖果"：你有10颗糖果，要分给你的5个好朋友，每个人分几颗呢？

第二个小任务是"选按钮"：分好糖果后，每个好朋友根据自己拿到的糖果数量，去选择按哪些按钮。

这样，你就不需要一下子想那么多事情了！先想怎么分糖果，再想每个人选什么按钮。是不是简单多了？

这就是"分层"的意思——把一个大麻烦变成两个小麻烦，一个一个来解决。

#### 📚 中学生级别解释

想象你是一个学校活动的总策划，你要组织一场全校性的知识竞赛。

**第一层决策（相当于高层MDP）**：
你需要决定给每个参赛队伍分配多少答题时间。比如：
- A队：30秒
- B队：25秒
- C队：35秒

这就是"预算分配"——你把总的时间资源（比如总共90秒）分配给不同的队伍。

**第二层决策（相当于底层MDP）**：
每个队伍拿到自己分配到的时间后，需要决定用这些时间去回答哪些题目。比如：
- A队有30秒，可以选择回答1道难题（30秒）或者3道简单题（每题10秒）
- B队有25秒，可以选择自己的答题策略
- C队有35秒，也可以选择自己的答题策略

这就是"节点选择"——每个队伍根据自己的时间预算，选择最优的答题组合。

**两层的关系**：
第一层的决定（时间分配）限制了第二层的选择范围。A队不可能用40秒去答题，因为你只给了它30秒。这就是"高层的动作成为底层的约束"。

**为什么要分层？**
如果不分层，你需要在同一时间考虑所有队伍的时间分配和题目选择，这是非常复杂的决策。通过分层，你可以：
1. 先在宏观层面做资源分配（时间分给谁）
2. 再在微观层面做具体选择（选哪些题）

这样就把一个复杂的"维数灾难"问题，分解成了两个相对简单的子问题。

#### 🎓 研究生级别解释

在马尔可夫决策过程（MDP）的理论框架下，我们面临的是一个**高维状态-动作空间**的优化问题。具体来说：

**原始MDP的维数灾难**：
- 状态空间：需要同时跟踪所有传感器的状态（N个传感器 × 每个传感器的可能状态）
- 动作空间：需要同时为所有传感器做出决策（N个传感器的节点选择的笛卡尔积）
- 复杂度：状态空间和动作空间的规模呈指数级增长（O(某个大数的N次方)）

**分层MDP的核心思想**：**决策解耦（Decision Decoupling）**

**第一层：高层MDP（High-level MDP）**
- **决策变量**：预算分配向量 b = (b₁, b₂, ..., bₙ)
  - bᵢ 表示分配给传感器i的采样预算
  - 约束条件：Σbᵢ = B（总预算）
- **状态空间**：聚合的系统状态（如整体不确定性水平）
- **目标**：在总预算约束下，最优地分配资源给各传感器
- **特点**：这是一个**资源分配问题**，状态和动作空间的维度较低（O(N)）

**第二层：底层MDP（Low-level MDP）**
- **决策变量**：节点选择 x = (x₁, x₂, ..., xₙ)
  - xᵢ 表示传感器i选择的采样节点
  - 约束条件：xᵢ ∈ 可行集合，且成本不超过bᵢ
- **状态空间**：单个传感器的局部状态
- **目标**：在给定预算bᵢ下，为传感器i选择最优采样节点
- **特点**：这是一个**约束优化问题**，可以**分解为N个独立的子问题**

**两层之间的耦合机制**：
```
高层输出 → 底层约束
─────────────────────
预算bᵢ   → 节点xᵢ的可行域
```

数学上，这种分层结构可以表示为：

**高层问题**：
```
max   E[V_high(s, b)]
b
s.t. Σbᵢ = B
     bᵢ ≥ 0
```

**底层问题**（对每个传感器i）：
```
max   Q_low(sᵢ, xᵢ | bᵢ)
xᵢ
s.t. cost(xᵢ) ≤ bᵢ
     xᵢ ∈ 𝒳ᵢ
```

**理论优势**：
1. **计算复杂度降低**：从指数级O(M^N)降到多项式级O(N×M)
2. **并行化**：底层的N个子问题可以并行求解
3. **模块化**：高层和底层可以分别使用不同的算法
4. **可解释性**：预算分配有明确的物理意义

**实际应用中的对应关系**：
| 抽象概念 | 具体应用 |
|---------|---------|
| 高层状态 | 整个传感器网络的信息熵、总不确定性 |
| 高层动作 | 预算分配方案（多少采样资源给每个传感器）|
| 底层状态 | 单个传感器当前的采样位置、读数 |
| 底层动作 | 选择下一个采样节点（具体去哪个位置）|
| 奖励信号 | 信息增益、预测误差减少 |

这种分层建模方法在强化学习领域被称为**Options框架**或**Feudal RL（封建强化学习）**，其核心思想就是通过时间或空间的抽象来处理复杂决策问题。

## 段落2：高层MDP定义

### 【英文原文】

**High-level MDP.** At the high level, the state sₕᵢgₕ at time step t represents the global uncertainty of the field. The action aₕᵢgₕ determines the budget allocation for all sensors. Specifically, aₕᵢgₕ = [b₁, b₂, ..., bₙ] where bᵢ is the budget allocated to sensor i, and Σᵢ bᵢ = B is the total budget. The reward function rₕᵢgₕ aims to maximize the information gain. After allocating budgets, the high-level agent triggers the low-level agents to perform sampling.

### 【简体中文翻译】

**高层MDP。**在高层，时刻t的状态sₕᵢgₕ表示场的全局不确定性。动作aₕᵢgₕ确定所有传感器的预算分配。具体而言，aₕᵢgₕ = [b₁, b₂, ..., bₙ]，其中bᵢ是分配给传感器i的预算，且Σᵢ bᵢ = B为总预算。奖励函数rₕᵢgₕ旨在最大化信息增益。在分配预算后，高层智能体触发底层智能体执行采样。

### 【三梯度深度解释】

#### 🐣 3岁小孩级别解释

想象你在玩一个"寻宝游戏"：

**状态（sₕᵢgₕ）是什么？**
就是"你现在有多不知道宝藏在哪里"。如果你完全不知道，状态就是"很迷糊"；如果你有点线索了，状态就是"有点方向"。

**动作（aₕᵢgₕ）是什么？**
就是你决定把你的"寻宝小帮手"派到哪里去。
比如你有5个小帮手，你可以这样分配：
- 小帮手1：去花园找3分钟
- 小帮手2：去厨房找2分钟
- 小帮手3：去房间找1分钟
- 小帮手4：去车库找3分钟
- 小帮手5：去地下室找1分钟

这就是[a₁, a₂, a₃, a₄, a₅] = [3, 2, 1, 3, 1]，总共是10分钟。

**奖励（rₕᵢgₕ）是什么？**
就是你找到多少宝藏的线索。找到的线索越多，奖励就越大！

**最后发生了什么？**
你分配好任务后，就喊一声："小帮手们，出发吧！"然后每个小帮手就去自己分配的地方开始找宝藏了。

#### 📚 中学生级别解释

想象你是救灾指挥中心的负责人，需要在一个受灾地区进行救援搜索。

**状态（sₕᵢgₕ）——全局不确定性**
这个状态描述的是整个受灾地区"我们还有多少地方不清楚"。可以用地图上的"未知区域百分比"来表示：
- 如果地图上80%的区域都是白色的（未探索），状态就是"高度不确定"
- 如果只有20%是白色的，状态就是"相对确定"

**动作（aₕᵢgₕ）——预算分配**
你有5个救援队（相当于5个传感器），总共有100个小时的救援时间（总预算B=100）。你需要决定给每个救援队分配多少时间：

```
aₕᵢgₕ = [b₁, b₂, b₃, b₄, b₅]
       = [25, 15, 20, 20, 20]

意思是：
- 救援队1：分配25小时
- 救援队2：分配15小时
- 救援队3：分配20小时
- 救援队4：分配20小时
- 救援队5：分配20小时

检查：25+15+20+20+20 = 100 ✓
```

**奖励（rₕᵢgₕ）——信息增益**
救援队搜索完后，会报告他们发现了什么（被困者的位置、道路状况等）。
- 如果他们报告了很多有价值的新信息，奖励就高
- 如果他们报告的都是我们已经知道的信息，奖励就低

**触发底层**
你（高层指挥官）分配好时间后，就通知各救援队队长（底层智能体）："你们有X小时，去搜索吧！"然后每个队长根据自己获得的时间，制定具体的搜索路线。

**为什么这样设计？**
- 状态关注"全局"：你不需要知道每个角落的细节，只需要掌握整体情况
- 动作关注"分配"：你决定资源（时间）如何分配，而不是具体去哪里
- 奖励关注"信息"：目标是要获得最多的新信息

#### 🎓 研究生级别解释

在分层强化学习的理论框架下，高层MDP的形式化定义如下：

**状态空间 Sₕᵢgₕ**：

```
sₕᵢgₕ(t) = U_global(t)
```

其中U_global(t)表示时刻t的全局不确定性度量。常见的定义包括：

1. **基于信息熵的定义**：
   ```
   U_global(t) = H[p(θ|Dₜ)] = -∫ p(θ|Dₜ) log p(θ|Dₜ) dθ
   ```
   其中θ是场的参数，Dₜ是到时刻t收集的所有数据。

2. **基于预测方差定义**：
   ```
   U_global(t) = Σᵢ σ²(xᵢ)
   ```
   其中σ²(xᵢ)是位置xᵢ处的预测方差。

3. **基于互信息的定义**：
   ```
   U_global(t) = I(θ; Dₜ) = H(θ) - H(θ|Dₜ)
   ```

**动作空间 Aₕᵢgₕ**：

```
aₕᵢgₕ = b = (b₁, b₂, ..., bₙ) ∈ ℝⁿ
```

约束条件：
```
Σᵢ bᵢ = B          （预算守恒）
bᵢ ≥ 0, ∀i         （非负性）
bᵢ ≤ b_max, ∀i     （单传感器上限）
```

这是一个**单纯形（Simplex）**上的优化问题。动作空间的维度是N-1（因为Σbᵢ=B的限制减少了一个自由度）。

**状态转移动力学**：

```
sₕᵢgₕ(t+1) = fₕᵢgₕ(sₕᵢgₕ(t), aₕᵢgₕ(t))
```

具体而言：
```
U_global(t+1) = U_global(t) - IG(aₕᵢgₕ(t))
```

其中IG(aₕᵢgₕ(t))是由于执行动作aₕᵢgₕ(t)（即预算分配b）而获得的信息增益。

**奖励函数 rₕᵢgₕ**：

有两种主要的设计方式：

1. **基于信息增益的奖励**：
   ```
   rₕᵢgₕ(t) = U_global(t) - U_global(t+1)
            = IG(b(t))
   ```

2. **基于长期目标奖励**：
   ```
   rₕᵢgₕ(t) = -U_global(t+1)  // 不确定性越小越好
   ```

**目标函数**：

```
max  E[Σₜ γᵗ rₕᵢgₕ(t)]
b₁...bₜ
s.t. Σᵢ bᵢ(t) = B(t), ∀t
```

**关键特性分析**：

1. **时间抽象（Temporal Abstraction）**：
   - 高层的每个"决策时刻"对应底层的多个执行步骤
   - 高层决定"战略"，底层负责"战术"

2. **状态聚合（State Aggregation）**：
   - 高层状态是底层状态的聚合函数
   - 减少了需要考虑的维度

3. **分解性**：
   ```
   IG(b) = Σᵢ IGᵢ(bᵢ)
   ```
   总信息增益可以分解为各传感器的贡献之和（假设传感器独立）

**实际算法实现**：

使用深度强化学习（如DQN、PPO、Actor-Critic）时：

```python
# 伪代码
class HighLevelAgent:
    def __init__(self):
        self.state_dim = uncertainty_features
        self.action_dim = num_sensors

    def get_action(self, global_uncertainty):
        # 输入：全局不确定性状态
        # 输出：预算分配向量 [b₁, b₂, ..., bₙ]
        budget = self.policy_network(global_uncertainty)

        # 归一化确保Σbᵢ = B
        budget = budget / sum(budget) * total_budget
        return budget

    def compute_reward(self, old_uncertainty, new_uncertainty):
        # 信息增益 = 不确定性减少量
        return old_uncertainty - new_uncertainty
```

**与标准MDP的对比**：

| 特性 | 标准MDP | 高层MDP |
|-----|---------|---------|
| 状态粒度 | 每个传感器的详细状态 | 全局聚合状态 |
| 动作粒度 | 具体节点选择 | 资源分配 |
| 决策频率 | 每个采样步骤 | 每个采样轮次 |
| 目标 | 最大化采样效率 | 最大化全局信息增益 |

这种设计使得高层智能体专注于"资源配置"这一战略性问题，而将具体的"节点选择"战术性问题交给底层处理。

## 段落3：底层MDP定义

### 【英文原文】

**Low-level MDP.** At the low level, each sensor i has its own MDP defined by the tuple (𝒮ᵢ, 𝒜ᵢ, 𝒫ᵢ, 𝐑ᵢ, γᵢ). The state sᵢ represents the current sampling position of sensor i. The action aᵢ selects the next sampling node from the candidate set 𝒩ᵢ. The transition probability 𝒫ᵢ captures the movement dynamics of the sensor. The reward function rᵢ = -c(aᵢ) - λU(xₐᵢ) encourages the sensor to select nodes with low movement cost and high local uncertainty. Here c(aᵢ) is the movement cost from the current position to the selected node, and U(xₐᵢ) is the local uncertainty at the selected node. The budget constraint is enforced by terminating the episode when the cumulative cost exceeds the allocated budget bᵢ.

### 【简体中文翻译】

**底层MDP。**在底层，每个传感器i都有自己的MDP，由元组(𝒮ᵢ, 𝒜ᵢ, 𝒫ᵢ, 𝐑ᵢ, γᵢ)定义。状态sᵢ表示传感器i当前的采样位置。动作aᵢ从候选集𝒩ᵢ中选择下一个采样节点。转移概率𝒫ᵢ捕获传感器的运动动态。奖励函数rᵢ = -c(aᵢ) - λU(xₐᵢ)鼓励传感器选择移动成本较低且局部不确定性较高的节点。其中c(aᵢ)是从当前位置到所选节点的移动成本，U(xₐᵢ)是所选节点的局部不确定性。预算约束通过当累积成本超过分配的预算bᵢ时终止episode来强制执行。

### 【三梯度深度解释】

#### 🐣 3岁小孩级别解释

想象你是一个找宝藏的小帮手，你的工作是帮主人去找宝藏。

**状态（sᵢ）——你在哪里？**
就是你现在站着的地方。比如你现在在"大树下"。

**动作（aᵢ）——你要去哪里？**
主人告诉你："你可以去这几个地方找一找：石头后面、草丛里、小河边"。这就是候选集𝒩ᵢ。
你要从这三个地方选一个。

**奖励（rᵢ）——你怎么知道选得好不好？**
奖励有两个部分，我们要让它们越小越好（因为前面有负号）：

1. **移动成本（c(aᵢ)）**：就是你要走多远
   - 如果从大树到石头只要走2步，成本就是2
   - 如果从大树到小河要走100步，成本就是100
   - 我们希望你少走点路（省力气）

2. **局部不确定性（U(xₐᵢ)）**：就是那个地方"有多可能藏宝藏"
   - 如果石头后面很可能有宝藏，不确定性很高，我们应该去
   - 但前面有个负号，所以不确定性越高，奖励越"不那么负"（越好）

结合起来就是：
```
奖励 = -走路的步数 - λ × 那个地方的神秘程度
```

**预算约束（bᵢ）——你有多少力气？**
主人说："你今天只能走20步，走完了就要回家。"
这就是你的"预算"。
每次你走几步，就从预算里扣掉。当预算用完了，你就不能继续找了。

**一个小例子**：
```
初始：在大树下，预算=20步
第1次：走到石头后面（3步），预算剩17步
第2次：走到草丛里（5步），预算剩12步
第3次：走到小河边（8步），预算剩4步
第4次：想走到桥边（需要10步），但预算只有4步了！
      → 不能去了，任务结束
```

#### 📚 中学生级别解释

想象你是一个外卖配送员，负责在一个区域内送餐。

**状态（sᵢ）——当前位置**
你现在在哪个路口或建筑物。比如："中山路与解放路交叉口"。

**动作（aᵢ）——下一个配送点**
你的手机上显示有几个待配送的订单：
- 订单A：时代广场（距离1.2公里）
- 订单B：科技园（距离3.5公里）
- 订单C：住宅小区（距离0.8公里）

你需要选择先送哪一个。这就是从候选集𝒩ᵢ = {A, B, C}中选择。

**转移概率（𝒫ᵢ）——路况变化**
虽然你选择了去订单B，但实际到达时间和路线可能会受交通影响：
- 有90%的概率正常到达
- 有10%的概率遇到堵车，花费更多时间

**奖励函数（rᵢ）——如何评估选择好坏**
```
奖励 = -移动成本 - λ × 订单优先级
```

1. **移动成本（-c(aᵢ)）**：
   - 去时代广场：成本-5分钟
   - 去科技园：成本-15分钟
   - 去住宅小区：成本-3分钟
   （我们希望时间越短越好，所以用负号）

2. **订单优先级（-λU(xₐᵢ)）**：
   - 时代广场：紧急订单（不确定性高），λ × 10
   - 科技园：普通订单，λ × 5
   - 住宅小区：不急，λ × 2
   （优先级越高，我们越想先送，所以用负号让它"不那么负"）

**计算示例**（设λ=1）：
```
选A：奖励 = -5 - 10 = -15
选B：奖励 = -15 - 5 = -20
选C：奖励 = -3 - 2 = -5
```

虽然C的奖励最高（最不负），但A的综合价值可能更好（紧急且不太远）。

**预算约束（bᵢ）——工作时间限制**
公司规定：你一个班次只能工作4小时（240分钟）。

```
初始：预算 = 240分钟
第1单：送到C，耗时15分钟，预算剩225
第2单：送到A，耗时18分钟，预算剩207
第3单：送到B，耗时22分钟，预算剩185
...
```

当累积时间接近240分钟时，你就要返回站点，今天的工作结束了。

**为什么这样设计？**
- 状态：简单明了，只需要知道当前位置
- 动作：从有限的选择中选一个
- 奖励：平衡效率（时间）和效果（优先级）
- 预算：模拟真实世界的资源限制

#### 🎓 研究生级别解释

底层MDP是一个经典的约束马尔可夫决策过程（Constrained MDP），其形式化定义如下：

**MDP元组定义**：

对于每个传感器i，有：
```
MDPᵢ = (𝒮ᵢ, 𝒜ᵢ, 𝒫ᵢ, 𝐑ᵢ, γᵢ)
```

**1. 状态空间 𝒮ᵢ**：

```
sᵢ ∈ 𝒮ᵢ = 𝒳  （所有可能的采样位置）
```

状态可以是：
- **连续空间**：sᵢ = (x, y) ∈ ℝ²（平面上的坐标）
- **离散空间**：sᵢ ∈ {节点₁, 节点₂, ..., 节点ₘ}
- **混合空间**：sᵢ = (位置, 剩余预算)

**2. 动作空间 𝒜ᵢ**：

```
aᵢ ∈ 𝒜ᵢ = 𝒩ᵢ  （候选节点集）
```

其中𝒩ᵢ的定义方式包括：

a) **K近邻候选集**：
```
𝒩ᵢ = {xⱼ : d(xⱼ, sᵢ) ≤ r}
```
即当前位置半径r内的所有节点。

b) **不确定性引导候选集**：
```
𝒩ᵢ = TopK{U(xⱼ) : xⱼ ∈ 𝒳}
```
即不确定性最高的K个节点。

c) **全空间离散化**：
```
𝒩ᵢ = {网格中心₁, 网格中心₂, ..., 网格中心ₘ}
```

**3. 转移概率 𝒫ᵢ**：

```
𝒫ᵢ(sᵢ' | sᵢ, aᵢ) = P(sᵢ(t+1) = sᵢ' | sᵢ(t) = sᵢ, aᵢ(t) = aᵢ)
```

对于确定性运动（如无人机）：
```
𝒫ᵢ(sᵢ' | sᵢ, aᵢ) = 1  if sᵢ' = aᵢ
                   = 0  otherwise
```

对于随机运动（如受环境影响的传感器）：
```
𝒫ᵢ(sᵢ' | sᵢ, aᵢ) ~ N(aᵢ, σ²)
```

**4. 奖励函数 𝐑ᵢ**：

论文中的奖励函数是：
```
rᵢ = -c(aᵢ) - λ·U(xₐᵢ)
```

这是一个**加性奖励函数**，包含两个组成部分：

**a) 成本项 -c(aᵢ)**：

移动成本的定义可以是：
- **欧几里得距离**：c(aᵢ) = ||sᵢ - aᵢ||₂
- **曼哈顿距离**：c(aᵢ) = |x₁ - x₂| + |y₁ - y₂|
- **能量消耗**：c(aᵢ) = E(sᵢ → aᵢ)
- **时间成本**：c(aᵢ) = t(sᵢ → aᵢ)

使用负号的原因：我们要**最小化**成本，这在RL框架中等同于**最大化**负成本。

**b) 信息项 -λ·U(xₐᵢ)**：

局部不确定性的定义：
```
U(x) = σ²(x)  （克里金方差）
```
或
```
U(x) = H[Y(x) | D]  （条件熵）
```

λ是**权衡参数**（trade-off parameter）：
- λ = 0：只考虑移动成本，不考虑信息增益（贪婪移动）
- λ → ∞：只考虑信息增益，不考虑移动成本（信息贪婪）
- λ ∈ (0, ∞)：平衡两者

**奖励函数的设计原理**：

这个奖励函数实际上是在优化一个**多目标优化问题**：

```
min  c(aᵢ)
aᵢ
s.t. maximize U(xₐᵢ)
```

通过加权求和，转化为单目标问题：
```
max  -c(aᵢ) - λU(xₐᵢ)
aᵢ
```

等价于：
```
min  c(aᵢ) + λU(xₐᵢ)
aᵢ
```

**5. 折扣因子 γᵢ**：

```
γᵢ ∈ [0, 1)
```

在有限horizon问题中（有预算约束），γᵢ通常设为1（无折扣）。

**预算约束的数学表达**：

论文采用**episode终止**的方式来约束预算：

```
定义累积成本：Cₜ = Σᵢ₌₁ᵗ c(aᵢ)

终止条件：if Cₜ > bᵢ then episode_terminates
```

这等价于一个**约束优化问题**：

```
max  E[Σₜ rᵢ(t)]
{aᵢ(t)}
s.t. Σₜ c(aᵢ(t)) ≤ bᵢ
```

**底层MDP的Bellman方程**：

状态价值函数：
```
Vᵢ(sᵢ) = maxₐᵢ [rᵢ(sᵢ, aᵢ) + γᵢ E[Vᵢ(sᵢ')]]
```

动作价值函数：
```
Qᵢ(sᵢ, aᵢ) = rᵢ(sᵢ, aᵢ) + γᵢ E[Qᵢ(sᵢ', aᵢ')]
```

**策略πᵢ**：

```
πᵢ(aᵢ | sᵢ) = P(aᵢ | sᵢ)
```

最优策略：
```
πᵢ*(sᵢ) = argmaxₐᵢ Qᵢ*(sᵢ, aᵢ)
         = argmaxₐᵢ [-c(aᵢ) - λU(xₐᵢ) + γᵢ Vᵢ*(aᵢ)]
```

**深度强化学习实现**：

使用DQN（Deep Q-Network）：

```python
class LowLevelAgent:
    def __init__(self, sensor_id, lambda_param):
        self.sensor_id = sensor_id
        self.lambda_param = lambda_param
        self.q_network = QNetwork(state_dim, action_dim)

    def get_action(self, state, candidates, budget):
        # state: 当前位置 (x, y)
        # candidates: 候选节点列表 [(x1, y1), (x2, y2), ...]
        # budget: 剩余预算

        # 计算每个候选节点的Q值
        q_values = []
        for candidate in candidates:
            movement_cost = self.compute_cost(state, candidate)
            uncertainty = self.get_uncertainty(candidate)

            # 即时奖励
            reward = -movement_cost - self.lambda_param * uncertainty

            # 估计未来价值（通过Q网络）
            future_value = self.q_network.predict(candidate)

            # Q值 = 即时奖励 + 折扣的未来价值
            q_value = reward + self.gamma * future_value
            q_values.append(q_value)

        # 选择Q值最大的动作（考虑预算约束）
        valid_actions = [i for i in range(len(candidates))
                        if self.compute_cost(state, candidates[i]) <= budget]

        if valid_actions:
            best_action = valid_actions[np.argmax([q_values[i] for i in valid_actions])]
            return candidates[best_action]
        else:
            return None  # 预算不足，终止

    def compute_reward(self, current_pos, next_pos):
        cost = distance(current_pos, next_pos)
        uncertainty = self.get_uncertainty(next_pos)
        return -cost - self.lambda_param * uncertainty
```

**多传感器分解**：

关键洞察：N个传感器的底层MDP可以**完全独立**地求解！

```
总问题：max  Σᵢ E[Σₜ rᵢᵗ(t)]
        {aᵢ(t)}

分解为N个子问题：
max  E[Σₜ rᵢ(t)]  for i = 1, 2, ..., N
aᵢ
```

这允许：
1. **并行计算**：N个智能体同时运行
2. **分布式执行**：每个传感器独立决策
3. **可扩展性**：增加传感器不会导致组合爆炸

**与高层MDP的接口**：

```
高层输出 → 底层约束
─────────────────────
bᵢ       → episode终止条件
         → 候选集筛选（只考虑预算内可达的节点）
```

**理论保证**：

如果奖励函数满足特定条件（如可分解性），则：
```
Q_total(s₁, ..., sₙ, a₁, ..., aₙ) = Σᵢ Qᵢ(sᵢ, aᵢ)
```

这意味着**分布式求解是全局最优的**。

## 段落4：两层联动机制

### 【英文原文】

The interaction between the two levels follows an options framework. The high-level policy πₕᵢgₕ selects a budget allocation option o = [b₁, ..., bₙ], which initiates the low-level policies πᵢ for each sensor. Each low-level policy executes a sequence of primitive actions (node selections) until the budget constraint is satisfied. The intra-option policy of the low-level MDP is conditioned on the allocated budget and aims to maximize local information gain within the budget limit. The termination condition βᵢ for sensor i is triggered when the cumulative sampling cost exceeds bᵢ.

### 【简体中文翻译】

两层之间的交互遵循Options框架。高层策略πₕᵢgₕ选择一个预算分配选项o = [b₁, ..., b�_n]，该选项为每个传感器启动底层策略πᵢ。每个底层策略执行一系列原语动作（节点选择），直到满足预算约束。底层MDP的内部选项策略以分配的预算为条件，旨在在预算限制内最大化局部信息增益。传感器i的终止条件βᵢ在累积采样成本超过bᵢ时被触发。

#### 🎓 研究生级别解释

这段描述的是经典的**Options框架**（Sutton, Precup & Singh, 1999），这是强化学习中**时间抽象（Temporal Abstraction）**的核心方法。

**Options框架的数学定义**：

一个Option是一个三元组：
```
o = (𝓘, πₒ, β)
```

其中：
- **𝓘 ⊆ 𝒮**：初始状态集（ initiation set）
- **πₒ : 𝒮 × 𝒜 → [0, 1]**：选项策略（ intra-option policy）
- **β : 𝒮 → [0, 1]**：终止条件（ termination condition）

在本论文中：

**高层作为Option选择器**：

```
πₕᵢgₕ : 𝒮ₕᵢgₕ → Δ(𝒪ₕᵢgₕ)
```

其中：
```
𝒪ₕᵢgₕ = {o₁, o₂, ..., oₘ}
       = {[b₁¹, ..., bₙ¹], [b₁², ..., bₙ²], ...}
```

每个option oₖ 对应一个特定的预算分配方案。

**底层作为Option执行器**：

对于每个传感器i，有：
```
oᵢ = (𝓘ᵢ, πᵢ(·|bᵢ), βᵢ(bᵢ))
```

**1. 初始条件 𝓘ᵢ**：

```
𝓘ᵢ = {sᵢ ∈ 𝒮ᵢ : bᵢ > 0}
```

即：只要分配的预算大于0，option就可以启动。

**2. 内部策略 πᵢ(·|bᵢ)**：

这是**条件策略**，以预算bᵢ为条件：
```
πᵢ(aᵢ | sᵢ, bᵢ) = P(aᵢ | sᵢ, bᵢ)
```

目标函数：
```
max  E[Σₜ rᵢ(t)]
πᵢ
s.t. E[Σₜ c(aᵢ(t))] ≤ bᵢ
```

这是一个**约束马尔可夫决策过程**的解。

**3. 终止条件 βᵢ**：

论文中使用的是**硬终止条件**：
```
βᵢ(sᵢ, Cₜ, bᵢ) = 1  if Cₜ ≥ bᵢ
               = 0  otherwise
```

其中Cₜ = Σᵢ₌₁ᵗ c(aᵢ)是累积成本。

也可以使用**软终止条件**：
```
βᵢ(sᵢ, Cₜ, bᵢ) = sigmoid(Cₜ - bᵢ)
```

**半马尔可夫决策过程（SMDP）**：

Options框架将底层MDP提升为SMDP：

```
𝒮ₕᵢgₕ = 𝒮  （高层状态空间）
𝒜ₕᵢgₕ = 𝒪  （高层动作空间 = Options集）
```

**SMDP的Bellman方程**：

```
Qₕᵢgₕ(s, o) = E[Σₖ₌₀ᵀ⁻¹ γᵏ rₜ₊ₖ + γᵀ Vₕᵢgₕ(s')]
```

其中T是option o的随机持续时间。

**两层交互的完整算法**：

```python
def hierarchical_execution():
    # 高层：选择Option
    s_high = get_global_state()
    o = pi_high(s_high)  # o = [b1, b2, ..., bn]

    # 底层：并行执行N个Options
    for each sensor i:
        state_i = get_sensor_state(i)
        budget_i = o[i]
        execute_low_level_option(i, state_i, budget_i)

def execute_low_level_option(i, state_i, budget_i):
    accumulated_cost = 0

    while accumulated_cost < budget_i:
        # 选择动作
        a_i = pi_low(state_i, budget_i - accumulated_cost)

        # 执行动作
        state_i, cost, reward = transition(state_i, a_i)
        accumulated_cost += cost

        # 更新底层策略
        pi_low.update(state_i, a_i, reward)

    # 预算用尽，终止option
    beta_i.trigger()

    return accumulated_cost, total_reward
```

**信息传递机制**：

```
┌──────────────────────────────────────────┐
│          高层MDP (SMDP level)             │
│  ┌────────────────────────────────────┐  │
│  │ 状态: s_high(t)                    │  │
│  │ 动作: o(t) = [b1, ..., bn]         │  │
│  │ 奖励: R_high = Σi Ri(oi)          │  │
│  │ 策略: π_high(s_high)              │  │
│  └────────────────────────────────────┘  │
└───────────────┬──────────────────────────┘
                │ 输出: budget_i
                ↓
┌──────────────────────────────────────────┐
│       底层MDP i (Primitive action level)  │
│  ┌────────────────────────────────────┐  │
│  │ 状态: s_i(t)                       │  │
│  │ 动作: a_i(t) (node selection)     │  │
│  │ 奖励: r_i = -cost - λ*uncertainty  │  │
│  │ 约束: Σ cost ≤ budget_i            │  │
│  │ 策略: π_i(s_i | budget_i)          │  │
│  │ 终止: β_i: Σcost > budget_i        │  │
│  └────────────────────────────────────┘  │
└───────────────┬──────────────────────────┘
                │ 输出: sequence of actions
                ↓
          [实际采样执行]
```

**理论性质**：

1. **分层一致性**：如果底层策略是约束最优的，则高层策略的优化会收敛到全局最优。

2. **可分解性**：
```
Q_high(s, o) = Σi E[Qi(s_i, oi)]
```

3. **时间抽象**：高层的每个决策对应底层的多个时间步。

**与标准强化学习的对比**：

| 特性 | 标准RL | Options框架 |
|------|--------|-------------|
| 时间粒度 | 单步 | 多步（option持续时间）|
| 动作空间 | 原语动作 | 临时抽象（options）|
| 规划horizon | 固定 | 可变（由终止条件决定）|

```python
    def __init__(self):

        self.low_level_networks = [LowLevelPolicy(i)
                                   for i in range(n)]

        state_high = get_global_state()
        option = self.high_level_network(state_high)

        # 底层执行option
        rewards = []
        for i in range(n):
            state_i = get_sensor_state(i)
            budget_i = option[i]

            # 执行直到终止
            while not terminated:
                action_i = self.low_level_networks[i](state_i, budget_i)
                next_state, reward, done = step(action_i)
                rewards.append(reward)
                state_i = next_state

                if budget_exhausted():
                    break

        # 更新高层和底层策略
        self.high_level_network.update(reward=sum(rewards))
        for i in range(n):
            self.low_level_networks[i].update(rewards[i])
```

**数学证明：分层优化的收敛性**

定理：如果底层策略πᵢ(·|bᵢ)对每个bᵢ都是最优的，则通过优化高层策略πₕᵢgₕ可以找到全局最优解。

证明思路：
```
V*(s) = maxo Q(s, o)
      = maxo E[Σi Vi(si, oi)]
      = Σi maxoi Vi(si, oi)      (如果可分解)
      = Σi Vi*(si)
```

因此分层优化不损失最优性。

### 【英文原文】

Algorithm 1 presents the hierarchical MDP algorithm. At each iteration, the high-level agent observes the global uncertainty state and computes the budget allocation using the high-level policy network. Then, for each sensor, the low-level agent receives its allocated budget and executes node selection actions sequentially until the budget is exhausted. The collected samples are used to update the Gaussian process model, which in turn updates the uncertainty field for the next iteration. This process continues until a convergence criterion is met or the maximum number of iterations is reached.

### 【简体中文翻译】

算法1给出了分层MDP算法。在每次迭代中，高层智能体观察全局不确定性状态，并使用高层策略网络计算预算分配。然后，对于每个传感器，底层智能体接收其分配的预算，并顺序执行节点选择动作，直到预算耗尽。收集的样本用于更新高斯过程模型，该模型进而更新下一次迭代的不确定性场。此过程持续进行，直到满足收敛准则或达到最大迭代次数。

#### 🎓 研究生级别解释

这是一个**自适应采样**的迭代优化算法，结合了**分层强化学习**和**高斯过程**。

**算法的数学框架**：

```
输入：
  - 初始场模型 GP₀
  - 传感器网络配置
  - 总预算 B
  - 最大迭代次数 T_max

输出：
  - 优化的采样轨迹 {τ₁, ..., τ_T}
  - 最终场模型 GP_T
```

**算法详解**：

**第t次迭代**：

**步骤1：状态观测**
```
sₕᵢgₕ(t) = U_global(t)

其中：
U_global(t) = Σₓ σ²ₜ₋₁(x)

σ²ₜ₋₁(x) 是 GPₜ₋₁ 在位置 x 处的预测方差
```

**步骤2：高层决策**
```
b(t) = πₕᵢgₕ(sₕᵢgₕ(t); θₕᵢgₕ)

其中：
  πₕᵢgₕ 是高层策略网络（参数为 θₕᵢgₕ）
  b(t) = [b₁(t), ..., bₙ(t)] 是预算分配向量
  Σᵢ bᵢ(t) = B（总预算约束）
```

策略网络的实现（使用深度神经网络）：
```python
class HighLevelPolicy(nn.Module):
    def __init__(self, state_dim, num_sensors):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(state_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, num_sensors),
            nn.Softmax(dim=-1)  # 确保输出为概率分布
        )

    def forward(self, state, total_budget):
        logits = self.network(state)
        budget_allocation = logits * total_budget
        return budget_allocation
```

**步骤3：底层执行**

对每个传感器i ∈ {1, ..., n}：

```
初始化：sᵢ ← 当前位置, Cᵢ ← 0（累积成本）

循环：
  aᵢ ← πᵢ(sᵢ, bᵢ - Cᵢ; θᵢ)        # 根据剩余预算选择动作
  (sᵢ', cᵢ, rᵢ) ← Transition(sᵢ, aᵢ) # 执行动作
  τᵢₜ ← τᵢₜ ∪ {(sᵢ, aᵢ, yᵢ)}        # 记录采样轨迹
  Cᵢ ← Cᵢ + cᵢ                      # 更新累积成本
  sᵢ ← sᵢ'                          # 更新状态

直到 Cᵢ ≥ bᵢ（预算耗尽）
```

底层策略的实现：
```python
class LowLevelPolicy(nn.Module):
    def __init__(self, state_dim, action_dim, lambda_param):
        super().__init__()
        self.lambda_param = lambda_param
        self.q_network = nn.Sequential(
            nn.Linear(state_dim + 1, 256),  # +1 for budget
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, action_dim)
        )

    def forward(self, state, budget):
        # 将状态和剩余预算拼接
        x = torch.cat([state, budget.unsqueeze(-1)], dim=-1)
        q_values = self.q_network(x)
        return q_values

    def select_action(self, state, budget, candidate_nodes):
        # 只考虑预算内的候选节点
        valid_nodes = [n for n in candidate_nodes
                      if cost(state, n) <= budget]

        if not valid_nodes:
            return None  # 预算不足

        q_values = self.forward(state, budget)
        best_action = valid_nodes[torch.argmax(q_values[valid_nodes])]
        return best_action
```

```
所有传感器完成采样后：
```

```python
def hierarchical_mdp_algorithm():
    # 初始化
    gp = initialize_gp()
    high_level_policy = HighLevelPolicy(state_dim, num_sensors)
    low_level_policies = [LowLevelPolicy(state_dim, action_dim, lambda_i)
                          for lambda_i in lambdas]

    for iteration in range(max_iterations):
        # 步骤1：观测全局状态
        global_state = compute_global_uncertainty(gp)

        # 步骤2：高层决策
        budget_allocation = high_level_policy(global_state, total_budget)

        # 步骤3：底层执行
        all_trajectories = []
        all_samples = []

        for i, sensor in enumerate(sensors):
            trajectory = []
            remaining_budget = budget_allocation[i]

            while remaining_budget > 0:
                # 当前状态
                current_state = sensor.get_position()

                # 选择动作
                action = low_level_policies[i].select_action(
                    current_state,
                    remaining_budget,
                    candidate_nodes[i]
                )

                if action is None:
                    break  # 预算不足

                # 执行动作
                new_state, cost, observation = sensor.execute(action)

                # 记录
                trajectory.append((current_state, action, observation))
                all_samples.append((new_state, observation))

                # 更新预算
                remaining_budget -= cost
                sensor.set_position(new_state)

            all_trajectories.append(trajectory)

        # 步骤4：更新模型
        gp = update_gp(gp, all_samples)

        # 步骤5：检查收敛
        new_uncertainty = compute_global_uncertainty(gp)
        if convergence_criterion(global_state, new_uncertainty):
            break

    return gp, all_trajectories
```

**算法的关键性质**：

1. **自适应采样**：每次迭代都根据当前不确定性调整采样策略

2. **闭环控制**：
```
观测 → 决策 → 行动 → 反馈 → 观测 → ...
```

3. **计算复杂度**：
   - 高层决策：O(|Sₕᵢgₕ| × |Aₕᵢgₕ|)
   - 底层执行：O(N × |Sᵢ| × |Aᵢ| × Lᵢ)
   - GP更新：O(M³)，M是样本总数

4. **并行化**：N个传感器的底层MDP可以完全并行执行

**算法改进方向**：

1. **经验回放**：存储历史经验，提高样本效率
2. **Actor-Critic架构**：同时优化策略和价值函数
3. **迁移学习**：利用预训练模型加速收敛
4. **分布式训练**：多个智能体独立学习和执行

## 总结：分层MDP的核心思想

通过以上五个段落的详细解析，我们可以总结出分层MDP的核心架构：

### 架构概览

```
┌─────────────────────────────────────────────────────────┐
│                    高层MDP（战略层）                      │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 状态：全局不确定性 U_global                         │  │
│  │ 动作：预算分配 [b₁, b₂, ..., bₙ]                   │  │
│  │ 目标：最大化全局信息增益                            │  │
│  │ 时间粒度：每次采样轮次                              │  │
│  └───────────────────────────────────────────────────┘  │
└───────────────────────┬─────────────────────────────────┘
                        │ 输出：预算约束
                        ↓
┌─────────────────────────────────────────────────────────┐
│                    底层MDP（战术层）                      │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 传感器1：状态s₁ → 动作a₁ → 奖励r₁（受预算b₁约束）  │  │
│  │ 传感器2：状态s₂ → 动作a₂ → 奖励r₂（受预算b₂约束）  │  │
│  │ ...                                              │  │
│  │ 传感器n：状态sₙ → 动作aₙ → 奖励rₙ（受预算bₙ约束）  │  │
│  │                                                 │  │
│  │ 目标：最大化局部信息增益 - 移动成本               │  │
│  │ 时间粒度：每个采样步骤                            │  │
│  │ 终止条件：累积成本超过预算                        │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 关键创新点

1. **决策解耦**：将"资源分配"和"节点选择"分离
2. **维度约简**：从指数复杂度降到多项式复杂度
3. **并行化**：N个底层MDP可独立求解
4. **可解释性**：预算分配有明确物理意义

### 与统一MDP的对比

| 特性 | 统一MDP | 分层MDP |
|------|---------|---------|
| 状态维度 | N × Sᵢ | Sₕᵢgₕ << N × Sᵢ |
| 动作维度 | M^N（组合爆炸）| N + M（可加分解）|
| 求解复杂度 | O((M×S)^N) | O(N×M×S) |
| 可并行性 | 有限 | 高度并行 |
| 可解释性 | 黑盒 | 分层清晰 |
