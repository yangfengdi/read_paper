## 5.1 Experimental Setup

### 【英文原文】

```
5.1 Experimental Setup

Datasets. We conduct experiments on two widely-used multi-modal intent discovery datasets: Multi-MIR and MIntRec.

• Multi-MIR [48] is collected from the public MIR dataset [31], which contains 13,952 multi-modal dialogues involving 5,580 users from a popular Chinese e-commerce platform. Each dialogue consists of both text and images. Following previous work [48], we split the dataset into training, validation, and test sets with a ratio of 8:1:1. There are 50 fine-grained intent labels in the Multi-MIR dataset.

• MIntRec [28] is a multi-modal intent recognition dataset that contains 10,417 multi-modal dialogues from Taobao, one of the largest Chinese e-commerce platforms. Each dialogue in MIntRec contains both textual and visual content. Following the dataset split in [28], we use 8,966 dialogues for training, 1,440 for validation, and 1,011 for testing. The dataset contains 18 intent categories.

Both datasets contain multi-modal dialogues with rich semantics, providing a comprehensive testbed for evaluating multi-modal intent discovery methods.
```

### 【简体中文翻译】

**5.1 实验设置**

**数据集。** 我们在两个广泛使用的多模态意图发现数据集上进行了实验：Multi-MIR和MIntRec。

• **Multi-MIR** [48] 是从公开的MIR数据集 [31] 中收集而来的，该数据集包含来自一个流行的中国电商平台的13,952个多模态对话，涉及5,580名用户。每个对话由文本和图像组成。遵循之前的工作 [48]，我们将数据集按8:1:1的比例分割为训练集、验证集和测试集。Multi-MIR数据集中有50个细粒度的意图标签。

• **MIntRec** [28] 是一个多模态意图识别数据集，包含来自淘宝（中国最大的电商平台之一）的10,417个多模态对话。MIntRec中的每个对话都包含文本和视觉内容。遵循 [28] 中的数据集划分方式，我们使用8,966个对话进行训练，1,440个用于验证，1,011个用于测试。该数据集包含18个意图类别。

这两个数据集都包含具有丰富语义的多模态对话，为评估多模态意图发现方法提供了全面的测试平台。

## 5.1 Implementation Details

### 【英文原文】

```
Implementation Details. Our model is implemented based on PyTorch framework [40]. We employ BERT-base-uncased [10] and ResNet-50 [18] as the text and image encoders, respectively. We set the hidden size of the transformer to 512 and the number of layers to 2. The batch size is set to 32. We use Adam optimizer [24] with an initial learning rate of 1e-4. We apply dropout with a rate of 0.1 to prevent overfitting. The model is trained for 30 epochs with early stopping based on validation performance. All experiments are conducted on a single NVIDIA RTX 3090 GPU.
```

### 【简体中文翻译】

**实现细节。** 我们的模型基于PyTorch框架 [40] 实现。我们分别采用BERT-base-uncased [10] 和ResNet-50 [18] 作为文本和图像编码器。我们将Transformer的隐藏层大小设置为512，层数设置为2。批量大小设置为32。我们使用Adam优化器 [24]，初始学习率为1e-4。我们应用速率为0.1的Dropout来防止过拟合。模型训练30个轮次，并根据验证性能使用早停法。所有实验都在单个NVIDIA RTX 3090 GPU上进行。

#### 🎓 研究生级别解释

**实现细节的工程与学术考量：**

**1. 编码器选择的技术分析：**

| 编码器 | 选择理由 | 参数量 | 特点 |
|--------|----------|--------|------|
| BERT-base-uncased | 文本理解的de facto标准 | 110M | 预训练语言模型，捕捉上下文语义 |
| ResNet-50 | 图像特征提取的经典选择 | 25.5M | 残差连接，训练稳定，特征提取能力强 |

**为什么选base而不是large？**
- **计算效率**：base版本参数适中，训练推理都快
- **性价比**：在多数任务上，base和large的性能差距不大
- **公平比较**：多数基线方法也使用base版本

**uncased的含义：**不区分大小写，对于中文任务影响不大，但对于英文来说意味着减少词汇表大小，提高效率。

**2. Transformer参数设计：**

```
参数决策背后的逻辑：
├── Hidden Size: 512
│   ├── 介于256和1024之间的折中值
│   ├── 足够表达复杂的跨模态交互
│   └── 不会过度增加计算量
├── Layers: 2
│   ├── 多模态融合通常不需要很深
│   ├── 主要编码工作已在BERT和ResNet完成
│   └── 2层足以学习模态间的交互
```

**3. 超参数的调优考量：**

**学习率（1e-4）：**
- 对于微调预训练模型，1e-4是一个保守但有效的选择
- 太大可能导致预训练知识被破坏
- 太小导致收敛慢

**批量大小（32）：**
- 32是深度学习中的"黄金数字"
- 平衡了GPU内存利用率和梯度估计的准确性
- 对于RTX 3090的24GB显存，32是安全的选择

**Dropout（0.1）：**
- 0.1是一个相对较低的值
- 说明模型不太容易过拟合（可能因为数据量足够）
- 或者主模型（BERT和ResNet）本身已经有正则化

**4. 训练策略的工程智慧：**

**早停法（Early Stopping）：**
```
训练过程监控：
├── 每个epoch结束后在验证集上评估
├── 记录最佳验证性能
├── 如果连续N个epoch（通常是5-10）没有提升
└── 则停止训练，回滚到最佳模型
```

**30个epoch的设计：**
- 设置一个较大的上限（30）
- 但实际上通过早停法可能10-15个epoch就停止
- 这样既保证有足够的训练时间，又避免浪费

**5. 硬件配置的说明：**

**NVIDIA RTX 3090单卡训练：**
- **显存（24GB）**：足够容纳BERT-base + ResNet-50 + 额外的Transformer
- **算力**：对于这个规模的模型，单卡训练是可行的
- **可复现性**：单卡训练消除了多卡训练的同步复杂性
- **成本效益**：3090是性价比较高的选择

**6. 实验的可复现性设计：**

这些细节的完整披露确保了：
- ✅ 其他研究者可以精确复现实验

## 5.1 Evaluation Metrics

### 【英文原文】

```
Evaluation Metrics. Following previous work [28, 48], we employ three standard metrics to evaluate the performance of intent discovery: Accuracy, Macro F1-score, and Weighted F1-score.

• Accuracy measures the ratio of correctly predicted samples to the total number of samples. It provides a straightforward evaluation of the overall classification performance.

• Macro F1-score calculates the F1-score for each category independently and then takes the average. This metric treats all categories equally, regardless of their size, making it suitable for imbalanced datasets.

• Weighted F1-score calculates the F1-score for each category and then takes the weighted average based on the number of samples in each category. This metric considers the class distribution and provides a comprehensive evaluation.

We report the mean and standard deviation of results over 3 runs to ensure the reliability of our experimental results.
```

### 【简体中文翻译】

**评估指标。** 遵循之前的工作 [28, 48]，我们采用三个标准指标来评估意图发现的性能：准确率、宏平均F1分数和加权F1分数。

• **准确率（Accuracy）**衡量正确预测的样本数与总样本数的比率。它提供了整体分类性能的直接评估。

• **宏平均F1分数（Macro F1-score）**独立计算每个类别的F1分数，然后取平均值。该指标平等对待所有类别，无论其大小如何，使其适用于不平衡数据集。

• **加权F1分数（Weighted F1-score）**计算每个类别的F1分数，然后根据每个类别中的样本数进行加权平均。该指标考虑了类别分布，并提供全面的评估。

我们报告3次运行结果的平均值和标准差，以确保我们实验结果的可靠性。

### 【三梯度深度解释】

#### 🧒 3岁小孩级别解释

想象你参加了一个考试，老师要给你打分。老师有三种不同的打分方法：

**方法一：准确率**
- 数一数你做对了多少题
- 比如100题里做对80题，就是80分
- 这是最简单直接的打分方法

**方法二：宏平均F1分数**
- 假设考试有语文、数学、英语三科
- 不管每科有多少题，每科都算一个分数
- 然后把三科分数平均一下
- 这样就算语文只有10题，数学有100题，两科也一样重要

**方法三：加权F1分数**
- 还是语文、数学、英语三科
- 但是题多的科目更重要
- 数学100题，语文10题，数学的分数就算得更重

**为了公平：**
- 老师让你考3次
- 取3次的平均分
- 还要看分数是否稳定（标准差）

#### 🎓 中学生级别解释

这就像期末考试的成绩单，需要从不同角度评估你的表现：

**1. 准确率（Accuracy）= 最直观的指标**

```
公式：Accuracy = 正确预测的数量 / 总数量

例子：
- 100个样本
- 预测对了85个
- Accuracy = 85/100 = 0.85 = 85%
```

**问题**：在类别不平衡时不准确
- 100个样本中，90个是A类，10个是B类
- 如果模型全部预测为A类，准确率是90%
- 但实际上模型什么都没学到！

**2. 宏平均F1分数（Macro F1）= 平等对待每个类别**

```
步骤：
1. 对每个类别单独计算F1分数
2. 把所有类别的F1分数平均

例子（3个类别）：
类别A的F1 = 0.80
类别B的F1 = 0.70
类别C的F1 = 0.90

Macro F1 = (0.80 + 0.70 + 0.90) / 3 = 0.80
```

**优点**：
- 小类别不会被忽略
- 适合评估模型在所有类别上的整体能力

**3. 加权F1分数（Weighted F1）= 考虑类别分布**

```
步骤：
1. 对每个类别单独计算F1分数
2. 按类别样本数加权平均

例子：
类别A：50个样本，F1 = 0.80
类别B：30个样本，F1 = 0.70
类别C：20个样本，F1 = 0.90

Weighted F1 = (50×0.80 + 30×0.70 + 20×0.90) / 100
             = (40 + 21 + 18) / 100
             = 0.79
```

**优点**：
- 反映真实场景中的性能
- 大类别的性能对整体影响更大

**4. 多次运行的统计**

```
运行3次的结果：
第1次：Accuracy = 85.2%
第2次：Accuracy = 84.8%
第3次：Accuracy = 85.5%

报告：85.17 ± 0.36%
       ↑ 平均值  ↑ 标准差
```

**为什么这么做？**
- 深度学习有随机性（初始化、dropout等）
- 多次运行能反映模型的真实性能
- 标准差小说明模型稳定

#### 🎓 研究生级别解释

**评估指标的理论基础与选择逻辑：**

**1. 准确率（Accuracy）的局限性与适用场景：**

```
Accuracy = (TP + TN) / (TP + TN + FP + FN)

适用于：
✓ 类别平衡的数据集
✓ 每个类别同等重要

不适用于：
✗ 类别严重不平衡
✗ 某些类别比其他类别更重要
```

**在不平衡数据上的问题：**
```python
# 例子：100个样本，90个正类，10个负类
# 模型预测全部为正类
TN = 0, FP = 10, FN = 0, TP = 90
Accuracy = 90/100 = 0.90  # 看起来很好！

但实际上：
- 负类的召回率为0%（完全没预测对）
- 模型没有任何判别能力
```

**2. F1分数的数学本质：**

```
F1 = 2 × (Precision × Recall) / (Precision + Recall)

其中：
Precision = TP / (TP + FP)  # 预测为正的样本中，真正为正的比例
Recall = TP / (TP + FN)     # 真正为正的样本中，被正确预测的比例

F1是Precision和Recall的调和平均：
- 两个都高时，F1才高
- 任何一个低都会拖累F1
```

**3. Macro F1 vs Weighted F1的深层差异：**

| 维度 | Macro F1 | Weighted F1 |
|------|----------|-------------|
| 计算方式 | 算术平均 | 加权平均 |
| 权重 | 每类权重=1/K | 权重=类别样本占比 |
| 偏好 | 偏好小类 | 偏好大类 |
| 适用场景 | 关注少数类的性能 | 关注整体性能 |
| 极端情况 | 1个样本的类=100个样本的类 | 大类性能主导 |

**数学表达：**

```
Macro F1 = (1/K) × Σ(F1_i)  for i = 1 to K

Weighted F1 = Σ(N_i × F1_i) / Σ(N_i)  for i = 1 to K
            = Σ(p_i × F1_i)  # p_i是类别i的占比
```

**4. 在意图发现任务上的意义：**

**场景分析：**
- **长尾分布**：电商意图中，"询问价格"可能很常见，但"投诉物流"可能很少见
- **业务价值不同**：某些少见的意图可能业务价值更高（如"退货申请"）

**指标选择策略：**

```
评估矩阵：
│                    │ Macro F1高 │ Macro F1低 │
├────────────────────┼────────────┼────────────┤
│ Weighted F1高      │ 理想状态   │ 只注重大类 │
│ Weighted F1低      │ 关注少数类 │ 都不好     │
```

**理想模型的表现：**
- Macro F1高 → 模型在所有意图类别上都表现好
- Weighted F1高 → 模型在常见意图上表现好
- 两者都高 → 模型全面优秀

**5. 多次运行的统计学考虑：**

```
结果报告格式：Mean ± Std

例子：85.2 ± 0.4

统计分析：
├── Mean（均值）：
│   ├── 估计模型的期望性能
│   └── 用于与其他方法比较
├── Std（标准差）：
│   ├── 衡量结果的稳定性
│   ├── 小 → 模型鲁棒，对初始化不敏感
│   └── 大 → 模型不稳定，需要调优
└── 样本量（n=3）：
    ├── 学术界常用n=3或n=5
    ├── 更大n值更可靠但计算成本高
    └── n=3在效率和可靠性间取得平衡
```

**统计显著性检验的隐含需求：**
如果Method A得85.2±0.4，Method B得84.8±0.5
- 需要t检验确定差异是否显著
- 如果p < 0.05，才能宣称A显著优于B

**6. 指标选择的学术规范性：**

```
遵循前人工作 [28, 48] 的意义：
├── 确保可比性
│   ├── 使用相同指标才能与基线公平比较
│   └── 读者能直观理解性能优劣
├── 确保合理性
│   ├── 这些指标在领域内被广泛认可
│   └── 避免指标选择的质疑
└── 确保完整性
    ├── Accuracy提供整体视图
    ├── Macro F1关注少数类
    └── Weighted F1关注整体分布
```

**潜在问题与讨论：**
- **为什么不报告AUC-ROC？**：多分类任务的AUC计算复杂，且在意图发现任务上不如F1直观
- **为什么不报告混淆矩阵？**：可能因为类别太多（50类），混淆矩阵难以可视化和分析

#### 🎓 中学生级别解释

现在我们进入了多模态方法的领域，这些方法同时使用文字和图片，但结合方式不同：

**Concat-BERT-ResNet（简单拼接）：**
```
工作流程：
1. 用BERT处理文字 → 得到768维向量
2. 用ResNet处理图片 → 得到2048维向量
```

**问题**：没有学习两种信息之间的关系
- 不知道哪些文字和哪些图片相关
- 只是机械地把信息放在一起

**BAN（双线性注意力网络）：**
```
工作流程：
1. 用BERT处理文字
2. 用ResNet处理图片
3. 用双线性注意力计算关系
   - 学习文字和图片之间的对应关系
   - 例如："红色"这个词和图片中的红色区域对应
4. 融合后进行分类

就像：
- 老师说"红色"，你在图片中找到红色的部分
- 这就是注意力机制
```

**优势**：知道两种信息如何相互关联

**实验设计的目的：**

```
性能对比（预期）：
Concat-BERT-ResNet < BAN < CoMat

证明：
1. 简单拼接不够好
2. 注意力机制有帮助
3. 但还需要更复杂的建模方法
```

#### 🎓 研究生级别解释

**简单融合方法的技术深度分析：**

**1. Concat-BERT-ResNet的特征级融合：**

```
数学表达：
├── 文本编码：h_text = BERT(x_text) ∈ R^768
├── 图像编码：h_image = ResNet(x_image) ∈ R^2048
├── 特征拼接：h_concat = [h_text; h_image] ∈ R^2816
└── 分类：y = softmax(W·h_concat + b)

其中：
- [;] 表示向量拼接操作
- W ∈ R^{C×2816} 是分类器权重矩阵
- C 是意图类别数
```

**技术局限：**

```
Concat-BERT-ResNet的问题：
├── 早期融合（Early Fusion）
│   ├── 在特征层面直接拼接
│   ├── 没有保留模态的独立性
│   └── 可能丢失模态特定的信息
├── 无交互建模
│   ├── 不建模h_text和h_image之间的关系
│   ├── 无法捕捉跨模态的语义对应
│   └── 例如："红色"文字与红色区域的关联
├── 维度灾难
│   ├── 768 + 2048 = 2816维
│   ├── 需要大量数据才能训练好
│   └── 容易过拟合
└── 特征尺度差异
    ├── 768维 vs 2048维，比例约1:3
    └── 视觉特征可能主导结果
```

**2. BAN（Bilinear Attention Network）的注意力融合：**

```
双线性注意力的数学表达：
├── 文本特征：T ∈ R^{d_t}（例如BERT的768维）
├── 图像特征：V ∈ R^{d_v}（例如ResNet的2048维）
├── 注意力映射：
│   └── A = σ(T^T · W · V) ∈ R^{d_t × d_v}
├── 加权特征：
│   ├── T' = T · A（文本注意力加权）
│   └── V' = V · A^T（图像注意力加权）
└── 融合特征：
    ├── h = T' ⊙ V'（逐元素乘积）
    └── ⊙ 表示Hadamard product

其中：
- W ∈ R^{d_t × d_v} 是可学习的权重矩阵
- σ 是激活函数（如sigmoid或tanh）
- ⊙ 表示逐元素乘法
```

**技术创新点：**

```
BAN的优势：
├── 双线性建模
│   ├── T^T·W·V 捕捉跨模态的二阶交互
│   ├── 比简单的拼接更有表达力
│   └── 能学习复杂的模态间关系
├── 注意力机制
│   ├── 自动学习哪些文本对应哪些图像区域
│   ├── 提供可解释性（可视化注意力图）
│   └── 降低了不相关信息的干扰
└── 逐元素乘积
    ├── 保留特征维度的对应关系
    └── 增强相关的特征，抑制不相关的
```

**3. 两种方法的对比分析：**

| 维度 | Concat-BERT-ResNet | BAN |
|------|-------------------|-----|
| 融合阶段 | 特征层面 | 注意力加权 |
| 交互建模 | 无 | 双线性交互 |
| 计算复杂度 | 低 | 中等 |
| 可解释性 | 低 | 中等（注意力可视化） |
| 参数量 | 较少（拼接后的分类器） | 较多（注意力权重矩阵） |
| 预期性能 | 基线水平 | 中等水平 |

**4. 基线设计的实验逻辑：**

```
实验设计的递进逻辑：
├── 单模态基线
│   └── 证明每种模态的独立价值
├── Concat-BERT-ResNet
│   └── 证明简单拼接不够，需要交互建模
├── BAN
│   └── 证明注意力有帮助，但还不够
└── CoMat（我们的方法）
    └── 证明复杂的模态协作建模是必要的
```

**预期性能梯度：**

```
性能排序（预期）：
Concat < BAN < SOTA < CoMat

原因分析：
├── Concat：
│   └── 无交互，性能受限于简单融合
├── BAN：
│   ├── 有注意力交互
│   └── 但可能受限于线性建模假设
├── SOTA：
│   ├── 更复杂的融合策略
│   └── 可能包含多种注意力机制
└── CoMat：
    ├── 协作建模（模态间互相帮助）
    └── 自适应融合（根据情况调整）
```

**最先进的方法。**

• **MIR** [48]：这是第一个探索从电商对话中发现多模态意图的工作。它采用协同注意力机制来建模文本和图像模态之间的交互。

#### 🎓 研究生级别解释

**SOTA方法的技术深度解析：**

**1. MIR - 协同注意力机制：**

```
技术架构：
├── 文本编码：BERT编码得到T ∈ R^{n×d_t}
├── 图像编码：CNN编码得到V ∈ R^{m×d_v}
├── 协同注意力：
│   ├── 文本→图像注意力：
│   │   └── A_{t→v} = softmax(T · W_1 · V^T)
│   ├── 图像→文本注意力：
│   │   └── A_{v→t} = softmax(V · W_2 · T^T)
│   └── 融合：[T ⊙ A_{v→t}; V ⊙ A_{t→v}]
└── 分类器：全连接层

创新点：
├── 双向注意力
│   ├── T→V：文本指导图像注意力
│   └── V→T：图像指导文本注意力
├── 对称设计
│   ├── 两种模态平等对待
│   └── 没有主次之分
└── 简单有效
    ├── 作为第一个工作，建立了基准
    └── 后续工作的基础
```

**2. MIntRec - 跨模态对齐与层次结构：**

```
技术创新：

(1) 跨模态对齐：
├── 目标：学习模态间的语义对应
├── 方法：
│   ├── 注意力对齐：A = softmax(T · W · V^T)
│   └── 对比损失：L_align = ||T_i - V_j||^2
└── 效果：相似的文本和图像特征更接近

(2) 层次结构：
├── 多粒度意图建模：
│   ├── 粗粒度：高层意图（如"购物"）
│   ├── 细粒度：具体意图（如"询问价格"）
│   └── 层次分类：先粗后细
├── 架构：
│   ├── 底层：细粒度检测器
│   ├── 中层：粒度融合
│   └── 顶层：粗粒度分类
└── 优势：
    ├── 符合意图的层次性本质
    ├── 提供更好的可解释性
    └── 可以处理新意图的泛化

数学表达：
└── 层次损失：
    L = L_fine + λ·L_coarse
```

**3. MMDF - 动态融合网络：**

```
核心创新：自适应融合

(1) 置信度估计：
├── 文本置信度：c_t = f(T) = σ(W_t · T + b_t)
├── 图像置信度：c_v = f(V) = σ(W_v · V + b_v)
└── 置信度向量：c = [c_t; c_v] ∈ R^2

(2) 动态权重：
├── 融合权重：α = softmax(W_c · c + b_c)
├── 加权融合：h = α_t · T + α_v · V
└── 权重归一化：α_t + α_v = 1

(3) 自适应机制：
├── 高置信度模态 → 高权重
├── 低置信度模态 → 低权重
└── 推理时动态调整

实例：
├── 场景1：清晰图片 + 模糊文字
│   └── c_v高 → α_v大 → 依赖视觉
├── 场景2：详细描述 + 低质图片
│   └── c_t高 → α_t大 → 依赖文本
└── 场景3：两者都清晰
    └── c_t, c_v都高 → 均衡融合
```
