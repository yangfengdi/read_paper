# 02. 核心创新点与研究基础

## A.pdf：*Sequential Stochastic Combinatorial Optimization Using Hierarchical Reinforcement Learning*（ICLR 2025）

### 1. 核心创新点、主要贡献、为何能发 ICLR

1. **首次系统化定义 SSCO 问题类**  
论文把“顺序 + 随机 + 组合优化”的联合决策问题（先分配多时段预算，再逐时段选节点）抽象为统一范式，而不是沿用“均匀预算分配”的简化假设。

2. **提出 WS-option 分层强化学习框架**  
构建两层 option-based HRL：
- 高层负责预算分配（option policy）
- 低层负责节点选择（intra-option policy）
并给出了两层 **MDP 的一致建模**，显式刻画跨层依赖。

3. **训练机制创新：wake-sleep + 分层学习范式解耦**  
为缓解上下层策略相互干扰，论文采用：
- 高层：MC 方法学习（稳定估计长期回报）
- 低层：TD/Q-learning 学习（提升样本效率与收敛速度）
再结合 wake-sleep 交替训练，降低“循环干扰”导致的不稳定。

4. **理论与实验闭环完整**  
给出两层策略的收敛性分析（在其设定下），并在两个不同 SSCO 实例（自适应影响力最大化、路径规划）上验证：效果、泛化性（可迁移到更大图）和计算效率优势。

**为何具备 ICLR 水平：**
- 问题重要且此前研究稀缺（SSCO 的通用 RL 框架不足）。
- 方法不是微调，而是“建模 + 算法 + 训练机制”一体化创新。
- 同时有理论支撑与跨任务实证，且强调泛化能力（ICLR 很看重）。

### 2. 研究基础（理论与前人工作）

1. **MDP / 强化学习基础**  
两层决策过程都建立在 MDP 建模上，属于标准 RL 建模范式。

2. **Option framework / HRL 基础**  
核心继承自 temporal abstraction 思路：
- Option framework（Sutton, Precup, Singh）
- Option-Critic（Bacon et al.）
论文在此基础上做了面向 SSCO 的任务特化与训练机制改造。

3. **值函数学习基础（MC 与 TD）**  
高层偏稳定估计、低层偏高效更新，本质是对 MC 与 TD 优缺点的工程化组合。

4. **图组合优化与图表示学习基础**  
问题场景与模型输入依托图结构，延续 RL for CO 与图表示学习脉络（如 structure2vec、GCN/GNN 系列）。

## B.pdf：*Learning Cut Selection for Mixed-Integer Linear Programming via Hierarchical Sequence Model*（ICLR 2023）

### 1. 核心创新点、主要贡献、为何能发 ICLR

1. **把 cut selection 从 P1/P2 扩展到 P1/P2/P3 的统一学习目标**  
论文指出并实证：不仅“选哪些 cut（P1）”与“选多少（P2）”重要，“选中的顺序（P3）”也显著影响求解效率。

2. **提出 HEM（Hierarchical Sequence Model）**  
两层结构：
- 高层策略学习 cut 数量 `k`
- 低层策略在给定 `k` 下，按序生成 cut 子集
低层把 cut selection 建模为 seq2seq 问题，而不是独立打分后截断。

3. **引入 Pointer Network 处理有序子集生成**  
通过 attention-as-pointer 逐步“指向”候选 cut，天然建模：
- cut 之间相互作用（互补/冗余）
- 顺序信息（P3）
这是相对传统 score-based 方法的关键提升。

4. **分层策略梯度训练**  
将 MILP 求解器交互过程形式化为 MDP，并推导 hierarchical policy gradient 来联合训练高低层策略。

5. **大规模、跨难度、含真实基准的实证**  
在合成 + 真实/高难 MILP（含 MIPLIB 2017）上优于人工规则与学习基线，并展示跨规模泛化能力。

**为何具备 ICLR 水平：**
- 将 OR 中关键工程问题重写为可学习的层次决策问题，问题定义有新意。
- 模型设计（层次 + 序列 + pointer）与训练推导完整，技术链条清晰。
- 实验覆盖面大，结果有实际 solver 效率价值，研究与应用双重贡献明显。

### 2. 研究基础（理论与前人工作）

1. **MILP / Branch-and-Cut 经典理论**  
建立在 cutting plane 与 branch-and-bound/branch-and-cut 体系之上（Gomory, Achterberg 等脉络）。

2. **MDP 与策略梯度 RL**  
将 cut selection 过程建模为 MDP，用策略梯度优化长期求解收益（而非单步贪心）。

3. **层次强化学习与时序抽象思想**  
高层决定“规模”（多少个），低层决定“内容与顺序”（哪些、先后），与 HRL 分而治之思想一致。

4. **序列建模与 Pointer Network**  
直接建立在 seq2seq 与 Pointer Network（Vinyals et al.）基础上，把组合子集选择转换为有序生成问题。

5. **学习型 cut selection 前沿工作**  
相对 Tang et al., Paulus et al., Huang et al., Turner et al. 等方法，HEM 的主要前进一步是：
- 不只学习打分
- 同时学习数量与顺序
- 通过序列概率建模 cut 间依赖

## 两篇论文的共性与差异（用于答辩时快速总结）

1. **共性**
- 都把复杂优化流程重构为强化学习决策问题（MDP）。
- 都采用“层次化”思想拆解难任务，提升可学习性与泛化性。
- 都强调超越人工启发式，并在大规模场景上证明效率收益。

2. **差异**
- A 更偏 **随机时序图优化**（预算分配 + 节点选择），关键在 option-HRL 与训练稳定性。
- B 更偏 **MILP 求解器内部策略优化**（cut 数量 + 子集顺序），关键在层次序列建模与 pointer 机制。

3. **一句话定位**
- **A**：用 option-based HRL 解决 SSCO 中“跨时间预算-动作耦合”的建模与稳定训练难题。  
- **B**：用 hierarchical sequence + pointer 解决 cut selection 中“选多少、选哪些、按什么顺序”的联合决策难题。
