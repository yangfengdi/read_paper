Here, we define the MDPs for the two layers of our hierarchical model (c.f. Figure 1). For ease of understanding, we will take the adaptive IM problem as a running example. More details of both problems are shown in Appendix C.2 and C.3, respectively.

### 3. 【三梯度深度解释】
- 3岁小孩级别：

- 中学生级别：

- 研究生级别：
  本段确立了建模范式：将 SSCO 拆分为互相耦合的双层 MDP。高层处理跨时间尺度的资源分配（budget allocation），低层处理给定预算约束下的组合动作构造（node set construction）。图 1 体现了“高层给出 K_t，低层在子步 j 内逐个选点，最终汇总为 a_t^{II} 并反馈到环境”的闭环。该段虽短，但等价于给出论文的核心结构假设：
  1. 时间抽象分层（time-scale abstraction）
  2. 动作空间分解（budget vs. node）
  3. 层间回馈耦合（low-level action quality 反作用于 high-level option value）

## 2) 3.2.1 高层 MDP：State 段

### 1. 【英文原文】
State The state s^I = (X, g) ∈ S includes two types of information: node features X (e.g., inactive or active in adaptive IM problem) and global information g (e.g., the remaining time steps T_r and the remaining budget K_r).

### 2. 【简体中文翻译】
状态：高层状态 \(s^I=(X,g)\in S\) 包含两类信息：节点特征 \(X\)（例如在 adaptive IM 中节点是未激活还是已激活），以及全局信息 \(g\)（例如剩余时间步 \(T_r\) 和剩余预算 \(K_r\)）。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  高层要先看看“现在世界是什么样子”。
  `X` 像一张点名表：谁亮了灯（激活），谁没亮。
  `g` 像日历和钱包：还剩几天、还剩几块钱。
- 中学生级别：
  这里把高层“观察”分成局部与全局：
  1. 局部结构信息：节点状态（谁已被影响）。
  2. 全局资源信息：剩余时间和剩余预算。
  这使高层能做“长线决策”：不是只看当前一时收益，而是按“还剩多少天、还有多少钱”来决定今天花多少。
- 研究生级别：
  \(s^I=(X,g)\) 的设计体现了可夫性需求与层级职责分离：
  1. \(X\) 承载图状态（传播相关 sufficient statistics）。
  2. \(g\) 承载规划边界条件（horizon/resource constraints）。
  对高层策略 \(\pi^I\) 而言，\(K_t\) 的最优性依赖未来可行域；\(T_r,K_r\) 直接定义未来 feasible set。若缺失 \(g\)，高层会出现“短视预算过耗”风险。该状态定义也为后续“高层发预算、低层执行节点选择”的接口提供了约束上下文。

## 3) 3.2.1 高层 MDP：Option 段

### 1. 【英文原文】
Option The option o^I represents the budget 0 ≤ K_t ≤ K_r allocated to the current time step t.

### 2. 【简体中文翻译】
选项（Option）：高层选项 \(o^I\) 表示在当前时间步 \(t\) 分配的预算 \(K_t\)，并满足 \(0\le K_t\le K_r\)。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  高层这一步只做一件事：决定“今天给下面小朋友几颗糖”（\(K_t\)）。不能给负数，也不能超过口袋里剩下的糖（\(K_r\)）。
- 中学生级别：
  在传统 RL 里动作可能直接是“选哪个节点”，这里不是。高层动作被定义成“预算数值”。这相当于先把大问题拆成两段：
  1. 先决定这轮能选几个点。
  2. 再由低层在这个配额内挑具体点。
  这种拆分让组合动作空间显著缩小。
- 研究生级别：
  将 \(o^I\) 定义为离散预算 \(K_t\) 实质上是一种 option-as-resource-commitment 设计：高层输出资源承诺，低层在条件策略 \(\pi^{II}(a\mid s,o^I)\) 下求局部最优组合。它把原始联合动作空间（预算 × 节点子集）因式分解为两阶段决策。该分解的收益在于：
  1. 高层负责跨期资源平滑/突发倾斜；
  2. 低层负责当期细粒度贪心或价值引导选择；
  3. 满足 \(K_t\le K_r\) 的硬约束天然保证可行性。

## 5) 核心公式（2）

### 1. 【英文原文】
\[
s_{t+1}^I = f(s_t^I, a_t^{II}) + \eta(s_t^I, a_t^{II}). \tag{2}
\]

### 2. 【简体中文翻译】
\[
s_{t+1}^I = f(s_t^I, a_t^{II}) + \eta(s_t^I, a_t^{II}). \tag{2}
\]
该式表示：下一时刻高层状态由“确定性更新项”与“随机扰动项”两部分共同组成。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  明天会怎样 = 按规则会变的那一部分 + 你猜不到的那一部分。
- 中学生级别：
  这个式子把状态变化拆解成“可计算部分”和“随机部分”：
  1. \(f\)：像固定规则引擎，告诉你执行动作后理论上怎么变。
  2. \(\eta\)：像噪声/随机事件，体现现实不确定性。
  这让模型既有结构性，又能表达随机传播。
- 研究生级别：
  该式是结构化随机转移建模：
  1. \(f\) 可视为可解释机制项（mechanistic dynamics），利于归纳偏置。
  2. \(\eta\) 吸收未建模随机性（stochastic propagation, exogenous uncertainty）。
  3. 在 value estimation 上，这种分解允许将转移不确定性局部化，便于分析 bias/variance。对 hierarchical credit assignment 而言，\(a_t^{II}\) 同时进入 \(f\) 与 \(\eta\)，说明低层动作既影响确定收益，也改变风险分布。

## 6) 3.2.1 高层 MDP：公式(2)后解释段

### 1. 【英文原文】
where f(s_t^I, a_t^{II}) is a deterministic function that updates the state s_t^I based on the current action a_t^{II}, while η(s_t^I, a_t^{II}) represents the stochastic component, which introduces randomness into the state transition, thereby capturing the stochastic nature of the environment. For example, in the adaptive IM problem, there is no deterministic component. Instead, the entire state transition is governed by the stochastic process η(s_t^I, a_t^{II}), which can be interpreted as the “activation process” within this problem.

### 2. 【简体中文翻译】
其中，\(f(s_t^I,a_t^{II})\) 是确定性函数，基于当前动作 \(a_t^{II}\) 更新状态 \(s_t^I\)；而 \(\eta(s_t^I,a_t^{II})\) 表示随机成分，它为状态转移引入随机性，从而刻画环境的随机本质。举例来说，在 adaptive IM 问题中不存在确定性成分，整个状态转移都由随机过程 \(\eta(s_t^I,a_t^{II})\) 主导，这可理解为该问题中的“激活传播过程”。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  有些游戏是“按按钮灯一定亮”，那就是确定的；但这个游戏更像“按了按钮，灯可能亮也可能不亮”，这就是随机的。
- 中学生级别：
  作者专门说 adaptive IM 基本由随机传播决定，意味着你选了种子节点后，后续激活并不是必然的。这告诉我们：高层预算决策必须考虑风险，不是只看平均值。
- 研究生级别：
  这里给出 domain-specific instantiation：adaptive IM 中 \(f\approx 0\)（或并入 \(\eta\)），转移核几乎完全由传播随机过程决定。方法论上，这意味着：
  1. 高层策略评估需要充分 Monte Carlo 估计以覆盖传播方差；
  2. 低层动作价值不能仅以单次 rollout 判断，否则高方差导致错配；
  3. “高层发预算”在该设定下本质是风险暴露控制（risk allocation over time）。

## 7) 3.2.1 高层 MDP：Reward 段

### 1. 【英文原文】
Reward The total reward depends on the problem of interest. In adaptive IM, it is the total number of influenced nodes (e.g., active and removed nodes). Then, the immediate reward r^I is the increase in the total reward.

### 2. 【简体中文翻译】
奖励：总奖励取决于具体问题。在 adaptive IM 中，总奖励是被影响节点总数（例如处于 active 和 removed 状态的节点数）。因此，即时奖励 \(r^I\) 定义为总奖励的增量。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  你影响到的小朋友越多，分数越高。每走一步，新增加了多少人，就加多少分。
- 中学生级别：
  这里把“累计目标”转成“每步增量奖励”，好处是训练时每个时间步都有反馈，学习更直接。高层关注的是每个时间步带来的新增影响。
- 研究生级别：
  以 total influenced nodes 作为任务回报，等价于在时间上优化增量和：\(R=\sum_t r_t^I\)。定义 \(r_t^I\) 为增量可减少 delayed reward 稀疏性，有利于高层价值学习稳定。更重要的是，它为后续低层奖励对齐（见式(4)）提供了统一标尺，使两层目标一致，缓解层间 objective mismatch。

## 8) 3.2.2 低层 MDP：State 段

### 1. 【英文原文】
State The state s^{II} is also defined as s^{II} = {X, g}.

### 2. 【简体中文翻译】
状态：低层状态 \(s^{II}\) 同样定义为 \(s^{II}=\{X,g\}\)。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  下面这一层也看同一张“世界地图”和“钱包日历”。
- 中学生级别：
  低层和高层共享状态要素，避免信息断裂。低层选节点时也需要知道全局剩余资源与时间，不然会做出只顾眼前的选择。
- 研究生级别：
  共享 \(X,g\) 体现 cross-level state consistency。虽然高层与低层关注粒度不同，但对同一环境使用兼容状态表示可降低 non-stationarity：高层预算变化不会导致低层观察空间定义跳变，有利于函数逼近泛化。

## 9) 3.2.2 低层 MDP：Option 段

### 1. 【英文原文】
Option The option o^{II} can be either 0 or 1, where “1” represents continuing to select nodes, and “0” represents not selecting any node and interacting with the environment.

### 2. 【简体中文翻译】
选项：低层选项 \(o^{II}\) 取值为 0 或 1，其中“1”表示继续选择节点，“0”表示不再选点并与环境交互。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  低层有两个按钮：
  1. 继续挑人（1）
  2. 停止挑人，去看环境怎么变化（0）
- 中学生级别：
  这是一个“继续/停止”控制信号，相当于低层内部终止机制。它让低层在子时间步里决定是否还要继续往集合里加节点。
- 研究生级别：
  二值 \(o^{II}\) 将低层过程刻画为可终止的序列构造：在预算允许下可迭代选点（continue），也可提前结束并触发环境转移（stop）。这与 option termination 思想一致，但被简化为显式 0/1 信号，降低实现复杂度并增强训练可控性。

## 10) 3.2.2 低层 MDP：Action 段

### 1. 【英文原文】
Action Two kinds of actions are defined. Given the current time step t, the action a_{t,j}^{II} is the node selected for a sub time step j (e.g., o_{t,j}^{II} = 1) or just the null action a_{t,∅} (e.g., o_{t,j}^{II} = 0). And the a_t^{II} is all the nodes selected in the current time step or the null action a_{t,∅} if no nodes are selected.

### 2. 【简体中文翻译】
动作：定义了两类动作。给定当前时间步 \(t\)，子时间步 \(j\) 的动作 \(a_{t,j}^{II}\) 可以是被选中的节点（例如 \(o_{t,j}^{II}=1\)），也可以是空动作 \(a_{t,\emptyset}\)（例如 \(o_{t,j}^{II}=0\)）。而 \(a_t^{II}\) 表示当前时间步内所有被选节点的集合；若未选任何节点，则为 \(a_{t,\emptyset}\)。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  每次你可以“挑一个人”，也可以“我不挑了”。这一轮结束后，把所有挑过的人放进一个小篮子，这个篮子就是 \(a_t^{II}\)。
- 中学生级别：
  低层动作有“单步动作”和“整步聚合动作”两级：
  1. \(a_{t,j}^{II}\)：第 \(j\) 次挑哪个点。
  2. \(a_t^{II}\)：把这一轮挑的点合并成集合，统一提交给环境。
  空动作保证“预算为0或提前结束”时流程仍定义完备。
- 研究生级别：
  该定义把组合优化转化为序列决策：集合动作 \(a_t^{II}\) 由子步动作轨迹 \((a_{t,1}^{II},...,a_{t,\tau}^{II})\) 生成。优点在于将指数级子集搜索转为逐点决策近似；同时引入 \(a_{t,\emptyset}\) 处理可变长度序列与零预算边界，保证 MDP 在所有分支上闭合。高层给出的 \(K_t\) 直接限制了子步上限 \(\tau\)，实现“预算-节点”联动。

## 11) 3.2.2 低层 MDP：State transition 段

### 1. 【英文原文】
State transition The state transition can occur either in a deterministic or stochastic way. If option o_t^{II} is 1 and the action is node v, we update the state of node v deterministically (e.g., activating node v). If option o is 0, the agent interacts with the environment as described in the higher layer MDP.

### 2. 【简体中文翻译】
状态转移：状态转移既可能是确定性的，也可能是随机性的。若选项 \(o_t^{II}=1\) 且动作为节点 \(v\)，我们以确定性方式更新节点 \(v\) 的状态（例如将节点 \(v\) 激活）。若选项 \(o=0\)，智能体按高层 MDP 中描述的方式与环境交互。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  你“选中一个人”这件事本身是确定的；但选完后世界怎么连锁变化，可能有随机性。
- 中学生级别：
  这段区分了两种变化：
  1. 低层内部操作（把某点加入已选集）通常是确定的。
  2. 当低层停止并把结果交给环境时，环境演化可能随机。
  于是模型把“可控步骤”和“不可控传播”分开处理。
- 研究生级别：
  该机制形成双阶段转移：
  1. Intra-step deterministic update（construction dynamics）
  2. Inter-step stochastic environment transition（propagation dynamics）
  这能减少低层学习中的噪声污染，因为选点动作的即时后果先在可控子系统内体现；随机性主要在交互节点处注入。对 credit assignment 来说，这提升了“哪一个点导致什么变化”的可辨识度。

### 1. 【英文原文】

\]

### 2. 【简体中文翻译】

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  先看现在有这些人时得几分，再把新朋友加进去看几分，多出来的就是这个朋友的功劳。
- 中学生级别：
  这是标准边际贡献定义。它能回答“在当前已选集合 \(A_t\) 下，再加 \(v\) 是否值得”。因为是条件增量，所以能体现节点之间的互补/重叠效应。
- 研究生级别：
  式(3)是组合决策中的局部增益估计器。它隐式捕获子模性或非子模性结构下的 context-dependent contribution。将动作价值从 set-level reward 拉回 element-level marginal，有助于把低层策略学习转化为 sequential greedy-like value improvement。其质量取决于 \(R_t\) 估计方差，故文中后续采用多次仿真平均。

## 15) 核心公式（4）

### 1. 【英文原文】
\[
r_{t,v}^{II} = \frac{m_{t,v}}{\sum_{u \in a_t^{II}} m_{t,u}}\left(r_t^I - r_{t,\emptyset}^{II}\right). \tag{4}
\]

### 2. 【简体中文翻译】
\[
r_{t,v}^{II} = \frac{m_{t,v}}{\sum_{u \in a_t^{II}} m_{t,u}}\left(r_t^I - r_{t,\emptyset}^{II}\right). \tag{4}
\]
该式表示：将“高层增量奖励减去空动作基线”这一总可分配奖励，按各节点边际奖励占比进行分摊，得到节点 \(v\) 的低层奖励。

### 3. 【三梯度深度解释】
- 3岁小孩级别：
  今天总共多拿了这么多糖（\(r_t^I-r_{t,\emptyset}^{II}\)），谁贡献大谁分得多，按比例分。
- 中学生级别：
  公式(4)做的是“比例分账”：
  1. 分子 \(m_{t,v}\)：节点 \(v\) 的贡献。
  2. 分母 \(\sum m_{t,u}\)：所有已选节点总贡献。
  3. 乘上可分配总量 \((r_t^I-r_{t,\emptyset}^{II})\)。
  这样每个节点奖励可加总回整体奖励，避免上下层目标不一致。
- 研究生级别：
  式(4)是 credit redistribution 机制：
  1. 先把高层当步收益校正为“相对空动作的净收益”；
  2. 再按 marginal contribution 比例投影到 token-level（节点级）奖励。
  其关键性质是 reward conservation（在常规条件下节点奖励和等于净收益），从而实现跨层一致目标优化。对训练而言，这缓解了低层仅见局部信号、高层见全局信号导致的梯度冲突，是“高层发预算、低层挑节点”能协同收敛的核心纽带。
