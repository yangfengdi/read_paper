# Reviewer 2（严苛版）：A.pdf 与 B.pdf 的批判性阅读

## A.pdf：3个逻辑漏洞 / 潜在缺陷 / 隐性假设

1. **把“累计奖励（cumulative reward）更高”近似当作“真实决策质量更好”**  
A 文主要用累计奖励比较方法（见 4.2、表1-3附近），但在真实场景里，累计奖励对奖励塑形、尺度系数、惩罚项非常敏感。一个策略可以“拿高分”但在稳健性、可解释性、风险控制上更差。该文隐含假设是：奖励函数与真实业务目标高度一致，这在复杂现实环境常不成立。

2. **统计显著性叙事存在“检验即证明”的倾向**  
文中反复强调“p-values ≤ 0.05”，并声称用 t-test 比标准差更合适（A.txt:661-662, 684, 727, 776, 823, 1922-1929）。但没有充分说明独立同分布、方差齐性、重复比较校正（多组/多设定）等前提。隐含假设是：这些统计前提天然满足，且“显著”就等于“效果稳健”，这在 RL 高方差设定下很容易失真。

3. **泛化与真实世界证据偏弱，存在“分布友好性”依赖**  
A 文称可从小图泛化到大图，并用单一 real-world 数据集 `power2500` 佐证；同时还明确写“真实数据的聚类模式更容易被本方法识别”（A.txt:2166-2168）。这其实是隐性前提：测试分布恰好具备对方法有利的结构。如果出现异质图结构、非平稳传播机制、预算/约束动态变化，结论可能明显回落。

## B.pdf：3个逻辑漏洞 / 潜在缺陷 / 隐性假设

1. **实验设置将 cut selection 问题“窄化”为 root node + one round**  
B 文实验遵循“只在根节点切割，且 cut separation round=1”（B.txt:430-432）。这有利于可比性，但隐含假设是：该简化设置能代表实际 MILP 求解流程。真实工业求解常涉及多节点、多轮切割与分支-切割耦合，方法在完整流程中的边际收益未被充分证明。

2. **训练/测试划分与模型选择策略可能高估泛化**  
B 文写“80/20 划分，且在 train set 上选 best model，再到 test 评估”（B.txt:800-803）。这容易引入选择偏置，且默认训练分布与部署分布接近。隐含假设是：同分布抽样足以代表跨实例族、跨行业、跨规模迁移，这在真实部署中通常不稳。

3. **把“顺序重要”转化为“层级序列模型必要”的因果链仍不够闭合**  
B 文通过 RandomAll/RandomNV 证明顺序影响显著（B.txt:190-222），再据此支持 HEM 的序列建模优势。但这里仍有跳跃：顺序重要并不自动推出“当前层级架构+RL训练”是最优实现；也可能是求解器内部数值稳定性/基结构敏感性在起主要作用。隐含假设是：观测到的性能差异主要由策略学习到的语义顺序贡献，而非求解器偶然耦合因素。

## 两篇论文的评估指标：是否可能在回避劣势？

## A.pdf 选了什么指标

- 主指标基本是**cumulative reward**（A.txt:671-672, 767等）。
- 报告方式强调 **t-test / p-value**（A.txt:661-662, 1922-1929），弱化了对方差分布、失败率、最坏分位数等风险指标的展示。

可能的回避点：
- 只看累计奖励，会掩盖“同分但路径更脆弱/更不稳定”的策略。
- 仅强调显著性，可能回避了**效应量大小**与**跨随机种子鲁棒性**。
- 对真实世界仅给较少案例（如 power2500），可能回避“跨域失效”问题。

## B.pdf 选了什么指标

- 主指标：**Time** 与 **PD integral**（B.txt:808-821）。
- 补充指标：Nodes、PD gap（主要放在附录，B.txt:809-810, 2708-2719）。
- 文中还明确：easy 集合更看 Time；medium/hard 更看 PD integral（B.txt:816-821）。

可能的回避点（尤其是 PD integral）：
- PD integral 是全过程面积型指标，能很好反映“收敛轨迹”，但也可能掩盖“最终是否达到可接受最优性证书”这类终局质量。
- 在统一 300s 截断下（B.txt:435），PD integral 优势可能部分来自“早期收敛更快”，但不必然意味着长时极限质量更优。
- 将 Nodes、PD gap 放到附录而非主表，客观上弱化了某些不利维度的可见度。

## 一句话总结（给你汇报时可直接用）

- **A 的核心风险**：把“奖励函数内的胜利”当成“现实目标的胜利”。  
- **B 的核心风险**：把“在受控求解设置中的过程指标优势”外推为“通用 MILP 场景中的整体优势”。
